# CPP-DSA-LEARNING

I started this with literally zero knowledge. Didn't know what a variable was. Didn't know why we write `int main()`. Watched the first CodeWithHarry video and just tried to not get lost.

A few months later I'm sitting here solving DSA problems, understanding two pointer logic, writing classes and recursion from scratch — and every now and then I get this overwhelming feeling when I think about how Google Maps works, how algorithms predict what you'll watch next, how recommendation engines know you better than you know yourself. And at the end of it all, it's just 0s and 1s.

That feeling is why I keep going.

## DSA Logic

A separate folder for logic-building. Things like:

- Palindrome, GCD, number reversal
- Array problems with multiple approaches

I use this section to actually think through problems rather than just solving them for the sake of a checkbox.

If I can't explain it in my comments, I don't really know it. That's the rule I follow.
